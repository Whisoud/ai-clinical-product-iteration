02
Step 02 · 导航与生成

左侧导航，
从零搭建产品结构

切到编辑视图后，导航树会变成可编辑态：新建、删除、拖拽全在左侧完成。 页面建好后，把名字和需求告诉 AI，让它在 pages/ 下生成 UI。

  • A · 新建 悬停节点，点 + 添加页面或文件夹
  • B · 拖拽 按住 ≡ 手柄，上下排序或拖入文件夹嵌套
  • C · 让 AI 实现 把页面名和需求发给 AI，由它在 pages/ 下生成 HTML
发给 AI 的 Prompt 示例
# 在 pages/dashboard.html 里生成一个销售分析仪表盘
> 用 Tailwind 写一个带折线图和数据表格的仪表盘
→ AI 在沙箱内生成高保真 UI，你直接在工作台里看到效果

给 AI 的约束：生成新页面时必须引入 page-bridge.js，否则 file:// 交付态下研发看不到 PRD 联动。

03
Step 03 · 原型即 PRD

原型即 PRD，
所见即所写

切到顶部「编辑视图」，悬停任意 UI 元素看到高亮，点击即写需求。 元素即条目，原型即文档 —— 不用再单独维护一份 PRD。 保存后去右下角「任务批处理站」，一键复制指令发给 AI。

  • A · 视图切到编辑视图
  • B · 悬停元素高亮，即 PRD 锚点
  • C · 点击写需求并绑定到该元素
